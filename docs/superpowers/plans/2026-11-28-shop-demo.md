# Демо для магазина: каталог магазина, тенге, заказ в WhatsApp — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Превратить конструктор из `index.html` в витрину конкретного магазина: его каталог и цены в тенге, кнопка «Заказать в WhatsApp» с готовым составом и ссылкой на макет для флориста.

**Architecture:** Логика без DOM выносится из `index.html` в классические скрипты `js/*.js` без сборки. Каждый скрипт объявляет глобальные `const` для браузера, а в конце экспортирует их через `module.exports`, если он определён, — так их тестирует `node --test`. Внешний вид позиций лежит в `js/library.js`, наличие и цены магазина — в `js/shop.js`, `js/catalog.js` соединяет их в тот же формат `KINDS/WRAPS/GIFTS/PRESETS`, с которым уже работает отрисовка.

**Tech Stack:** HTML/CSS/vanilla JS, встроенный тест-раннер Node (`node --test`, Node ≥ 18), без npm-зависимостей.

**Spec:** `docs/superpowers/specs/2026-11-28-shop-demo-design.md`

## Global Constraints

- Без сборки и без зависимостей: в `package.json` нет `dependencies` и `devDependencies`, только скрипт `"test": "node --test tests/"`.
- Страница работает и с GitHub Pages, и при открытии `index.html` как файла. Поэтому только классические `<script src>`, никаких `type="module"` и `fetch` своих файлов.
- Валюта — `₸`, разделитель тысяч — неразрывный пробел ` `: `formatMoney(12100) === '12 100 ₸'`.
- Весь интерфейс и текст сообщения на русском.
- Состояние обновляется только иммутабельно (`state = {...state, ...}`), как в текущем коде.
- Работа на ветке `feat/shop-demo` от `main`. Push и включение GitHub Pages — только после явного «да» пользователя.

## Review Focus

1. **Номер магазина не задан или записан «по-человечески»** (`+7 701 123-45-67`, `8 701 1234567`, пусто). Ожидание: номер нормализуется до `77011234567`. Если номер пустой или кривой, кнопка заказа неактивна и подписана «Номер магазина не настроен», а не открывает `wa.me/` без номера. Тесты — задача 1.
2. **Текст открытки с эмодзи, кавычками, переносами строк, `&`, `#`, `?`.** Ожидание: в WhatsApp приходит ровно этот текст, ничего не обрезано на `&` или `#`. Тест-раунд-трип через `URL` — задача 1.
3. **Магазин убрал позицию, которая есть в готовой композиции или в сохранённом букете покупателя.** Ожидание: такая композиция не показывается, сохранённые стебли этого вида отбрасываются, страница не падает. Тесты — задача 2.
4. **Испорченная, обрезанная мессенджером или старая ссылка на макет.** Ожидание: ссылка игнорируется, открывается сохранённый букет или первая композиция, без ошибки в консоли. Тесты — задача 4.
5. **Заказ только из подарков или пустой букет.** Ожидание: при пустом букете кнопка неактивна, заказ из одних подарков отправляется, а строки упаковки и ленты в нём не появляются. Тест — задача 1.

`const phone = normalizePhone(SHOP.whatsapp)`. Для обеих ссылок:
- букет пустой (`lines.length === 0`) → `aria-disabled="true"`, без `href`, текст «Добавьте цветы»;

### Task 4: Ссылка на макет для флориста

**Files:**
- Create: `js/share.js`, `tests/share.test.js`
- Modify: `index.html` — подключить `js/share.js`; `load()` (`index.html:381-393`) разделить на `restore(saved)` и чтение localStorage; функция `orderLink`; запуск в конце скрипта (`index.html:762`)

**Interfaces:**
- Produces:
  - `encodeBouquet(state): string` — base64url (без `=`, `+`→`-`, `/`→`_`) от UTF-8 JSON `{v:1, w:wrap, r:ribbon, e:seed, s:[[kind, x, y, rot, lift, manual ? 1 : 0], …], g:gifts, c:cardText | null}`. `x`, `y`, `rot`, `lift` округлены до целых, отсутствующий `lift` = 0. `seed` и порядок стеблей нужны, чтобы `arrange()` (`index.html:400`) разложил неперемещённые бутоны так же, как у покупателя, а `lift` — чтобы совпал вид сверху.
  - `decodeBouquet(code: string): {wrap, ribbon, seed, nextId, stems: [{id, kind, x, y, rot, lift, manual}], gifts, card:{on, text}} | null` — `null` при любой ошибке разбора, при `v !== 1` и при отсутствии массива `s`. `id` выдаются подряд с 1 в исходном порядке, `nextId = stems.length + 1`. Состав, цены и границы здесь не проверяются: это делает `sanitize` в `index.html`.
  - Кодирование через `TextEncoder` и `btoa`/`atob`: они есть и в браузере, и в Node ≥ 18.

- [ ] **Step 1: Написать падающие тесты `tests/share.test.js`**

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const { encodeBouquet, decodeBouquet } = require('../js/share.js');

const state = {
  wrap: 'kraft', ribbon: 'sage', view: 'side', seed: 3, nextId: 7,
  stems: [{ id: 4, kind: 'rose_red', x: 200.4, y: 180.6, rot: -12, lift: 20, manual: false },
          { id: 6, kind: 'daisy', x: 150, y: 210, rot: 8, manual: true }],
  gifts: { bear_small: 1 },
  card: { on: true, text: 'Мама, ты лучшая! 💐 & #1' },
};

test('bouquet survives a round trip', () => {
  const b = decodeBouquet(encodeBouquet(state));
  assert.equal(b.wrap, 'kraft');
  assert.equal(b.ribbon, 'sage');
  assert.equal(b.seed, 3);
  assert.equal(b.nextId, 3);
  assert.deepEqual(b.stems.map(s => [s.id, s.kind, s.x, s.y, s.rot, s.lift, s.manual]),
    [[1, 'rose_red', 200, 181, -12, 20, false], [2, 'daisy', 150, 210, 8, 0, true]]);
  assert.deepEqual(b.gifts, { bear_small: 1 });
  assert.deepEqual(b.card, { on: true, text: 'Мама, ты лучшая! 💐 & #1' });
});

test('code is URL-safe', () => {
  assert.match(encodeBouquet(state), /^[A-Za-z0-9_-]+$/);
});

test('a 51-stem bouquet fits in 2500 characters', () => {
  const stems = Array.from({ length: 51 }, (_, i) => ({ id: i + 1, kind: 'rose_powder', x: 100 + i, y: 150 + i, rot: -30 + i, manual: true }));
  assert.ok(encodeBouquet({ ...state, stems }).length <= 2500);
});

test('broken, truncated or foreign codes decode to null', () => {
  const good = encodeBouquet(state);
  for (const bad of ['', '!!!', good.slice(0, good.length / 2), btoa('{"v":2,"s":[]}'), btoa('[1,2,3]')]) {
    assert.equal(decodeBouquet(bad), null, bad);
  }
});

test('card off encodes as no card', () => {
  assert.deepEqual(decodeBouquet(encodeBouquet({ ...state, card: { on: false, text: 'черновик' } })).card, { on: false, text: '' });
});
```
