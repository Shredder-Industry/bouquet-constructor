# Конструктор букетов для цветочного магазина

Витрина магазина в браузере: покупатель собирает букет из цветов и зелени, выбирает упаковку, ленту и открытку, добавляет плюшевые игрушки и сладости. Сумма считается сразу, а кнопка «Заказать в WhatsApp» открывает чат с магазином, где состав уже набран.

Сейчас настроен магазин **Sana Flowers**. Цены пока примерные.

## Возможности

- Каталог из 12 цветов и видов зелени, 5 вариантов упаковки и 4 лент
- Макет букета в двух ракурсах, сбоку и сверху; бутоны можно перетаскивать мышью, пальцем или стрелками на клавиатуре
- Плюшевые игрушки и сладости, которые рисуются рядом с букетом
- 9 готовых композиций, 5 из них с подарком
- Открытка с текстом до 200 знаков
- Подсказка о нечётном числе цветов для подарка
- Заказ в WhatsApp с готовым сообщением и ссылкой на макет; кнопка «Скопировать состав»
- Отмена для «Очистить», выбора готовой композиции и открытия букета по ссылке
- Светлая и тёмная тема, адаптивная вёрстка с панелью итога на телефоне

## Как работает заказ

1. Покупатель нажимает «Заказать в WhatsApp». Открывается чат с номером магазина, сообщение уже заполнено: состав с ценами, текст открытки, итог в тенге.
2. В конце сообщения стоит ссылка «Макет: …». Флорист открывает её и видит тот же букет: цветы, упаковку, ленту, подарки, открытку и положение каждого бутона.
3. Оплата и доставка обсуждаются в переписке, как обычно.

Ссылка на макет появляется только на опубликованной странице (`http`/`https`). У локального файла адреса, который можно открыть с телефона, нет.

## Как настроить магазин

Всё про магазин лежит в `js/shop.js`:

| Поле | Что это |
|---|---|
| `id` | Короткое имя магазина латиницей, входит в ключ `localStorage` |
| `name`, `tagline` | Название и подзаголовок в шапке страницы |
| `whatsapp` | Номер в любом виде: `87067021665`, `+7 706 702-16-65`, `77067021665` |
| `currency` | Знак валюты, сейчас `₸` |
| `flowers`, `wraps`, `gifts` | Позиция → цена. **Нет позиции в списке — нет в наличии** |
| `ribbons` | Какие ленты есть |
| `cardPrice` | Цена открытки |
| `presets` | Готовые композиции. Композиция с позицией не из наличия скрывается сама |

Внешний вид позиций (название, тип цветка, цвета) задан в `js/library.js` и общий для всех магазинов. Новый вид цветка сначала добавляется туда, а потом получает цену в `js/shop.js`.

Если номер пустой или записан неверно, кнопка заказа неактивна и подписана «Номер магазина не настроен».

## Запуск

Сборки и зависимостей нет. Откройте `index.html` в браузере или включите GitHub Pages для ветки `main`.

Собранный букет хранится в `localStorage` браузера посетителя. На сервер он уходит, только если посетитель нажмёт «Показать вживую».

## Тесты

```bash
npm test
```

Нужен Node 18 или новее. Тесты лежат в `tests/` и проверяют сообщение о заказе, ссылку WhatsApp, объединение библиотеки с магазином и кодирование ссылки на макет.

## Фото «вживую» (ИИ)

Кнопка «Показать вживую» отправляет снимок макета на `api/realistic.js`. Функция просит модель Seedream 5.0 Flash Edit на fal.ai превратить макет в реалистичное фото букета 1024×1280. Ключ хранится только на сервере.

1. Скопируйте `.env.example` в `.env.local` и впишите `FAL_KEY` (ключ из fal.ai → Dashboard → Keys). `FAL_IMAGE_MODEL` можно оставить пустым, тогда используется `bytedance/seedream/v5/flash/edit`.
2. Локально запустите `node --env-file=.env.local tools/dev-server.js` и откройте http://localhost:3000.
3. Для продакшена нужен хостинг с серверными функциями, например Vercel: папка `api/` подхватывается сама, ключ задаётся в Environment Variables проекта. На GitHub Pages функция работать не будет.

Цена: около $0.027 за фото, оплата с баланса fal.ai. Лимит сайта: 10 запросов за 10 минут с одного IP.
